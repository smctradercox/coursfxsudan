# fxsudan

واجهة عربية RTL لموقع التسجيل في كورس التداول وقناة fxsudan الخاصة.

## التشغيل

```bash
npm install
npm run dev
```

## المزايا الحالية

- إنشاء حساب وتسجيل دخول مع حفظ بيانات كل مستخدم محلياً في المتصفح.
- عروض كورس SMC والقناة الخاصة.
- عرض شبكة USDT TRC20 والعنوان، مع زر نسخ العنوان.
- تأكيد الدفع يفتح رابط Telegram للحساب `@fxsudan1`.
- ملف شخصي لتعديل الاسم والنبذة وتسجيل الخروج.

هذه النسخة واجهة frontend تجريبية؛ الدفع لا يتم التحقق منه تلقائياً، ويحتاج ربط backend وبوابة دفع قبل الإطلاق العام.
